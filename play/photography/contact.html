Project Reflection

Developing the website was an interesting venture that sent me reading and viewing so many different types of websites so that I could build more idea of how to develop my website. It started with simple HTML which was mainly based on my recently attained website development learning curve. I had the option of integrating AI in the process but did not do so since I wanted to have an in-depth learning process. So, most of the work was done from reading different resources on HTML and CSS learn how to code especially the W3School.html. the platform has a profound level of learning material that played a huge role in the whole development process. The platforms easy code writing ant testing enable me to test each code before committing to it and this led to the overall development of the platform. Overall I feel with my next website design I will be able to even improve my development skill to integrate new and more useful HTML and CSS coding styles.
